# CrackHash

## Описание задачи
CrackHash — это распределенная система для получения исходного слова по его MD5-хэшу методом полного перебора (brute-force). 

Система состоит из Менеджера (Manager) и вычислительных узлов (Workers). 
Менеджер предоставляет REST API для клиентов, принимает запросы на взлом, разбивает общее пространство перебора паролей на равные части и делегирует задачи Воркерам. Воркеры выполняют вычисления и возвращают совпадения Менеджеру.

Также реализована обработка таймаутов (отмена зависших воркеров) и поддержка частично готовых результатов (сохранение найденных слов даже при отмене задачи по таймауту).

## Инструкция по запуску

Для развертывания системы необходимы Docker и Docker Compose.

1. Перейдите в корневую директорию проекта.
2. Выполните команду для сборки и запуска контейнеров (поднимется 1 менеджер и 3 воркера):
   ```bash
   docker-compose up --build
   ```
3. После запуска API менеджера будет доступно на порту `8080`.

Для остановки системы выполните:
```bash
docker-compose down
```
